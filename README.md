# 💪 ジム記録 (My Gym Record)

iPhoneのSafariからホーム画面に追加して使う、シンプルなフィットネスジム記録Webアプリ（PWA）。

## 機能

- 📝 **記録対象**: マシントレーニング / 有酸素運動 / 自重トレーニング / ストレッチ
- 📌 **前回値の自動表示**: 種目を選ぶと前回の重量・回数を自動入力（編集して保存可）
- 🏆 **自己ベスト表示**: マシン種目の最大挙上重量を自動表示
- 📅 **履歴表示**: 日付ごとに記録を確認、種別・種目でフィルタ可能
- 💾 **CSVエクスポート / JSONバックアップ**: Macへのデータ移行・バックアップに対応
- 📱 **PWA対応**: オフライン動作、ホーム画面追加でネイティブアプリのような体験

## セットアップ

iPhoneでの利用方法は [`iPhoneセットアップ手順.md`](iPhoneセットアップ手順.md) を参照してください。

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `index.html` | アプリ本体（HTML/CSS/JS、単一ファイル完結） |
| `manifest.json` | PWA マニフェスト |
| `icon-192.png` / `icon-512.png` | ホーム画面アイコン |
| `起動.command` | Mac でローカル動作確認用 |
| `iPhoneセットアップ手順.md` | 詳細セットアップ手順書 |

## ストレージ

- データは**端末のブラウザlocalStorage**に保存されます
- iPhone と Mac は別データ（自動同期なし）
- 端末間の移行は CSV / JSON エクスポート経由
